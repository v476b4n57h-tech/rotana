# ROTANA Hair Style

موقع صالون ROTANA ونظام الحجز والإدارة، مبني بـ Next.js و TypeScript و Supabase، ويُنشر على Vercel.

- **الخطة الهندسية الكاملة:** [`docs/ROTANA-PLAN.md`](docs/ROTANA-PLAN.md)
- **النسخة الأصلية:** الملف `index.html` في جذر المشروع، وهو محفوظ أيضاً بالعلامة `v0-static-demo`. **لا يُعدَّل**، وهناك اختبار آلي يتأكد من ذلك.

## حالة المشروع

| المرحلة                   | الحالة              |
| ------------------------- | ------------------- |
| 0. التحضير وتهيئة المشروع | ✅ منفّذة            |
| 1. نقل التصميم            | ⏳ بانتظار الموافقة |

## ماذا يوجد في المشروع؟

```
rotana/
├─ index.html              ← الموقع الأصلي (لا يُلمس)
├─ docs/ROTANA-PLAN.md     ← الخطة الهندسية
├─ src/
│  ├─ app/                 ← صفحات الموقع
│  │  ├─ layout.tsx        ← الإطار العام: اللغة والخطوط
│  │  ├─ page.tsx          ← الصفحة الرئيسية (مؤقتة في المرحلة 0)
│  │  └─ globals.css       ← الألوان والخطوط المنسوخة حرفياً من الأصل
│  ├─ config/features.ts   ← مفاتيح تشغيل/إطفاء الوظائف
│  ├─ i18n/                ← ملفات اللغات (الهولندية حالياً)
│  └─ lib/
│     ├─ env.ts            ← التحقق من الإعدادات
│     ├─ finance/          ← حسابات المال و BTW والنسب
│     └─ supabase/         ← الاتصال بقاعدة البيانات (يُفعّل في المرحلة 2)
├─ supabase/               ← إعدادات قاعدة البيانات والتعديلات عليها
├─ tests/
│  ├─ unit/                ← اختبارات سريعة للكود
│  └─ e2e/                 ← اختبارات تفتح الموقع في متصفح حقيقي
├─ .github/workflows/ci.yml ← فحص آلي على GitHub عند كل تعديل
└─ .env.example            ← نموذج للإعدادات (بدون أسرار)
```

## التشغيل على جهازك

تحتاج [Node.js](https://nodejs.org) الإصدار 22 أو أحدث.

1. ثبّت الحزم (مرة واحدة):

```bash
npm install
```

2. شغّل الموقع للتطوير، ثم افتح http://localhost:3000 في المتصفح:

```bash
npm run dev
```

## الأوامر

| الأمر               | ماذا يفعل                                        |
| ------------------- | ------------------------------------------------ |
| `npm run dev`       | يشغّل الموقع للتطوير، ويتحدث تلقائياً عند كل تعديل |
| `npm run build`     | يبني النسخة النهائية للنشر                       |
| `npm run lint`      | يفحص جودة الكود                                  |
| `npm run typecheck` | يفحص أنواع TypeScript                            |
| `npm run format`    | ينسّق الكود تلقائياً                               |
| `npm test`          | يشغّل الاختبارات السريعة                          |
| `npm run test:e2e`  | يشغّل اختبارات المتصفح (بعد `npm run build`)      |
| `npm run check`     | يشغّل كل الفحوص السابقة دفعة واحدة                |

## قواعد مهمة

- **لا تضع أي مفتاح سري في الكود أو في git.** الأسرار تُضاف في ملف `.env.local` على جهازك (وهو مستثنى من git)، أو في إعدادات Vercel.
- **لا بيانات زبائن حقيقية أثناء التطوير.** نستخدم بيانات وهمية فقط.
- **فرع `main` لا يُدمج فيه شيء** إلا بموافقة صاحب المشروع.
